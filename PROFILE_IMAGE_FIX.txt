PROFILE IMAGE UPLOAD FIX

The Admin Profile page now supports TWO methods:

METHOD 1 - NORMAL UPLOAD
Admin -> Profile -> Upload profile picture
Select PNG/JPG/JPEG/WEBP and Save profile.

METHOD 2 - SUPABASE URL FALLBACK
Use this if the Streamlit uploader shows a red exclamation mark.

1. Open Supabase.
2. Open Storage.
3. Open the portfolio-assets bucket.
4. Upload your profile JPG/PNG.
5. Click the uploaded image.
6. Copy its public URL.
7. Return to the Streamlit portfolio.
8. Admin -> Profile.
9. Paste the URL into "Profile image URL (optional)".
10. Click Save profile.

The public homepage will use that image directly.

IMPORTANT
The app keeps XSRF/CORS security enabled. It does not disable Streamlit security
just to work around a failed uploader.

If the red ! remains, hover/click it and note the exact error. A 403 upload error
is generated by the Streamlit upload endpoint before Supabase receives the file.
