PROFESSIONAL CV FORMAT UPDATE

The old public CV was a LinkedIn-style 4-page export with a sidebar and a very long summary.

This update changes the portfolio to a clean professional CV format:
- 2-page layout
- no sidebar
- no profile photo
- ATS-friendly single-column structure
- strong name/header area
- short professional profile
- compact core expertise
- clear role/company/date alignment
- achievement-focused bullets
- selected projects
- education
- selected certifications
- navy + teal professional styling

PUBLIC DOWNLOAD:
The site's normal Download CV button now downloads:
assets/Bethuel_Sang_Professional_CV.pdf

CV BUILDER:
The Admin CV Builder now uses Modern Professional as the default format.

INSTALL:
1. Stop Streamlit with Ctrl+C.
2. Copy app.py and cv_generator.py into your current portfolio folder.
3. Copy these files into assets:
   Bethuel_Sang_Professional_CV.pdf
   Bethuel_Sang_Professional_CV.docx
4. Replace data/profile.json, or simply change cv_file in Admin/Profile to:
   assets/Bethuel_Sang_Professional_CV.pdf
5. Restart Streamlit.

For Render deployment, upload/push this updated folder to GitHub and redeploy.
